# MultiShield Extension
This branch maintains only the extension, which is separate from Multi-shield-Frontend.

## Instructions to run this extension
1. Toggle on Developer Mode

2. Load Unpacked

3. Select this folder

## Run samples for testing
1. Have python on your device

2. Change to the directory `/samples`

3. Run python http server, the port number can be anything unused `python -m http.server 8001`

4. Open it on your web
- http://localhost:8001/ecommerce-ads.html 
- http://localhost:8001/email-phishing.html
- http://localhost:8001/job-ads.html
